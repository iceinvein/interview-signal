**How it works**
- **One rule orders PENDING:** VIP first, then by order number. Order numbers only go up, so this puts a new VIP behind existing VIPs and ahead of all Normal orders. It also puts an order from a removed bot back exactly where it was.
- **Assigning work:** each idle bot takes the order at the front of PENDING whenever an order is added, a bot is added, or a bot finishes.
- **Removing a bot:** "- Bot" always removes the newest one. If it was cooking, it stops and the order goes back to PENDING. The next bot starts that order again from zero (a full 10 seconds).
- **Choices I made where the brief is open:**
  - order numbers start at 1001, to match the sample output;
  - bot numbers are never reused;
  - `build.sh` only checks the code's syntax, because there are no dependencies and nothing to compile.
