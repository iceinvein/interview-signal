**How it's built:**
- **`src/orderController.js`**: the order and bot logic, with no printing. The pending queue is always sorted VIP first, then by order number. Order numbers only go up, so a new VIP order lands behind earlier VIPs and ahead of normal orders. A cancelled order also goes straight back to its original position with no extra tracking.
- **`src/logger.js`**: turns what the controller does into timestamped log lines.
- **`src/cli.js`**: `npm start` opens the interactive CLI. Commands are `n`, `v`, `+`, `-`, `s`, `wait <sec>`, `help` and `q`. `run.sh` feeds `scripts/demo.txt` through the same command loop, so the CI output comes from the same code you'll demo in the interview.
- **`SOLUTION.md`**: usage, design and assumptions. For example, order numbers start at 1001, and a cancelled order starts its 10 seconds over when it's picked up again.
