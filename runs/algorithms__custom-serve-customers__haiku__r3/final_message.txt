Done! I've implemented the function using a min-heap to efficiently track which server becomes free earliest at each step.

**Algorithm:**
1. Initialize a min-heap with all `servers` being free at time 0
2. For each customer (in strict order):
   - Pop the server with the earliest free time
   - Calculate when service starts: `max(arrival_time, server_free_time)`
   - Calculate when service ends: `start_time + duration`
   - Push the server back to the heap with its new free time
   - Record the finish time

**Complexity:** O(n × log m) where n is customers and m is servers, which handles the constraints efficiently (up to 200,000 customers and 100,000 servers).
