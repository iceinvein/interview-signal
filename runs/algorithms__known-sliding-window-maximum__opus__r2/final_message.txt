I implemented `maxSlidingWindow` in `solution.ts`, and it gives correct results in testing.

**How it works:** it keeps a list of positions whose values get smaller from front to back. For each new element, it first drops values from the back that are less than or equal to the new one, since they can't be the largest in any later block. Then it adds the new position and drops the front one if it has left the block. The front of the list always holds the largest value in the current block. Each element goes in and out of the list at most once, so it runs in O(n) time with O(n) extra memory, which is fine for n = 100,000. It has no imports.

**Testing:**
- The standard example `[1,3,-1,-3,5,3,6,7]` with `k=3` returns `[3,3,5,5,6,7]`, which is correct.
- `[1]` with `k=1` returns `[1]`.
- 500 random arrays of different lengths and `k` values all matched a simple check that takes the max of each block directly.
