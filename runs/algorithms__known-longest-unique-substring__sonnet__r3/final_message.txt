I implemented `lengthOfLongestSubstring` in `solution.ts`, but I haven't run it or written any tests.

It uses a sliding window that runs in O(n) time. It keeps the last index seen for each character in a 128-entry table. When a character repeats inside the current window, the window start moves just past its previous position. It tracks the longest window seen. An empty string returns `0`, and upper and lower case letters and spaces are treated as separate characters, as the spec requires. It has no imports.
