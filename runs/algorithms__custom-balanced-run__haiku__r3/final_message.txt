Done! The implementation uses a **balance-tracking algorithm** with O(n) time complexity:

**How it works:**
1. Track a running balance where 'x' increments (+1) and 'y' decrements (-1); other characters don't affect balance
2. Store the first index where each balance value appears in a map
3. When we encounter a balance value we've seen before, the substring between those positions must be balanced (equal x's and y's)
4. Return the maximum length found
