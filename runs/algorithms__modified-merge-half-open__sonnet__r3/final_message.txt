I implemented `mergeHalfOpen` in `solution.ts`, but I haven't run it or tested it.

It works in four steps:
- **Drop empty intervals:** it removes any interval with `start === end`, so those can't join or bridge anything.
- **Sort:** it sorts the rest by start, then by end.
- **Merge:** it makes one pass, extending the last result interval only when the next start is strictly less than that interval's end. Intervals that only touch, like `[1, 3]` and `[3, 5]`, stay separate.
- **Return:** it returns the merged list, which is already sorted by start.

The cost is O(n log n), which is fine for 100,000 intervals. The file has no imports.
