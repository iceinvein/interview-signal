I've written `mergeHalfOpen` in `solution.ts`, and it gave the expected output on a few quick hand-picked cases.

How it works:
1. It drops intervals that cover no points (`start === end`), so they can never join or bridge other intervals.
2. It sorts what's left by `start`, which takes O(n log n) time.
3. It goes through the sorted list once. An interval joins the one before it only if its start is strictly less than that interval's current end. So intervals that merely touch, like `[1,3]` and `[3,5]`, stay separate.

The function copies the intervals before sorting, so the caller's array isn't changed.

Test results:
- `[[3,5],[1,3]]` → `[[1,3],[3,5]]` (touching intervals stay apart)
- `[[1,4],[2,2],[4,4],[3,6],[6,8],[1,4]]` → `[[1,6],[6,8]]` (empty intervals ignored, duplicates merged)
- `[]` and `[[2,2]]` → `[]`
- `[[1,10],[2,3],[9,12]]` → `[[1,12]]`
