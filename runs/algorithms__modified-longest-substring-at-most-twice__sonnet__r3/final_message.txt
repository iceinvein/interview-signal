I wrote `longestSubstringAtMostTwice` in `solution.ts` using a sliding window, but I haven't run or tested it.

It keeps a count for each ASCII code and moves the right edge of the window forward one character at a time. If a character's count goes above 2, it moves the left edge forward until that count is back to 2. It tracks the longest window seen along the way. That runs in O(n) time with a fixed-size count array, and an empty string returns `0`. The file has no imports.
