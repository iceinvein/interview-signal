I wrote `lengthOfLIS` in `solution.ts`, but I haven't run or tested it.

It keeps a sorted array of the smallest possible last element for each subsequence length. For each number, it binary-searches for the first entry that is greater than or equal to it and replaces that entry. If none is, the number is appended. The final array length is the answer.

Because it finds the first entry `>= x`, equal values replace an entry instead of extending the subsequence, so only strictly increasing runs count. It runs in O(n log n), which is fine for 100,000 elements. It has no imports.
