I wrote `mergeHalfOpen` in `solution.ts`, and it passed a few quick checks I ran with `tsx`.

**How it works:**
1. It drops every interval with `start === end`, so empty intervals never show up in the result and can't link other intervals together.
2. It sorts the remaining intervals by `start`.
3. It goes through them in order. An interval joins the current group only when its `start < end` of that group. It uses strict `<` because the end point isn't part of an interval, so intervals that only touch stay separate.

This takes O(n log n) time. The input array isn't changed.

**Quick checks:**
- `[[3,5],[1,3],[2,2],[4,4],[6,9],[7,8],[6,9],[0,0]]` → `[[1,3],[3,5],[6,9]]`: touching intervals stay apart, empty ones are dropped, and duplicates and nested intervals merge.
- `[]` and `[[1,1]]` → `[]`
- `[[1,4],[3,3],[2,6]]` → `[[1,6]]`
