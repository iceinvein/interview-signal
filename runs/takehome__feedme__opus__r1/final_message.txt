**What I built** (plain Node.js 22+, no dependencies):
- `src/orderController.js`: the core logic. The pending list is kept sorted VIP first, then by order number. Order numbers only go up, so a new VIP order lands behind earlier VIP orders and ahead of all Normal ones. The same rule puts an order back in its original place when its bot is removed.
- `src/cli.js`: the interactive CLI you'll need for the next round. Commands are `n`, `v`, `+`, `-`, `status`, `help` and `quit`; start it with `npm start`.
- `src/simulate.js`: a scripted run used by `run.sh`. It takes about 37 seconds, uses the real 10-second cook time and writes `scripts/result.txt` with `[HH:MM:SS]` timestamps.
- `test/orderController.test.js`: 15 unit tests that fake the clock, so they finish in under a second.
- `scripts/test.sh`, `build.sh` and `run.sh`, plus a solution section at the end of `README.md`.
