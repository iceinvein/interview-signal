I implemented `longestNonDecreasing` in `solution.ts` and haven't run it or any tests.

It keeps an array where entry `i` is the smallest possible last element of a non-decreasing subsequence of length `i + 1`. For each number, a binary search finds the first entry strictly greater than it and overwrites that entry, or appends the number if none is greater. Using "strictly greater" is what lets equal values extend a subsequence, so `[2, 2, 2]` gives `3`. The answer is the array's final length. It runs in O(n log n), which is fine for 100,000 elements, and needs no imports.
