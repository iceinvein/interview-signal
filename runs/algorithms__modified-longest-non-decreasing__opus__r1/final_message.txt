I've implemented `longestNonDecreasing` in `solution.ts`. It runs in O(n log n) time.

**How it works:** it keeps an array `tails`, where `tails[k]` is the smallest value that can end a non-decreasing subsequence of length `k + 1`. For each number, a binary search finds the first entry in `tails` that is strictly greater than it. The number replaces that entry, or is added to the end if there isn't one. Searching for "strictly greater" rather than "greater or equal" is what lets equal values extend a subsequence. The answer is the final length of `tails`.

**Tested with:**
- `[2,2,2]` → 3
- `[5]` → 1
- `[3,1,2,2,1,3]` → 4
- `[5,4,3]` → 1
- `[1,3,2,3,3,0,4]` → 5
- A 100,000-element input finished in about 2.5 ms.

The file has no imports.
