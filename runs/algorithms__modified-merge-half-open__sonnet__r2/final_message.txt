I implemented `mergeHalfOpen` in `solution.ts`. I haven't run it or written any tests.

It works in four steps:
- It drops every interval where `start === end`. Those cover no points, so they can't join or bridge anything.
- It sorts the rest by `start`, then by `end`.
- It sweeps through them once. An interval merges into the previous result only if its `start` is strictly less than that result's `end`. The merged `end` becomes the larger of the two.
- Intervals that only touch, like `[1, 3]` and `[3, 5]`, stay separate.

Sorting makes it O(n log n), which is fine for 100,000 intervals. The file has no imports.
