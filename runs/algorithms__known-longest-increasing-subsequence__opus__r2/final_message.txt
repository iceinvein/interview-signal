I implemented `lengthOfLIS` in `solution.ts`. It runs in O(n log n) time, which handles 100,000 elements easily.

**How it works:** it keeps a list where entry `k` is the smallest possible last value of an increasing subsequence of length `k+1`. For each number, a binary search finds the first entry that is greater than or equal to it and replaces that entry. If no such entry exists, the number is added to the end. Because the search stops on equal values too, a repeated value replaces an entry instead of making the list longer, so equal values never count as increasing. The answer is the list's final length.
