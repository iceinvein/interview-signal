I implemented `coinChangeLimited` in `solution.ts`, but I haven't run it or tested it.

It uses a DP over amounts. For each denomination it takes the minimum over 0 to `counts[i]` coins of that value. A monotonic deque does this per residue class, so each denomination costs O(amount). The total is about 12 × 10,000 operations, however large the counts are. It returns `-1` if `amount` is unreachable and `0` when `amount` is `0`. A count of `0` skips that denomination. The file has no imports.
