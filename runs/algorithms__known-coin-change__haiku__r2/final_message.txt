Done. I've implemented the coin change function using dynamic programming.

**Approach:**
- Create a DP array where `dp[i]` represents the minimum coins needed for amount `i`
- Initialize `dp[0] = 0` and all others to `Infinity`
- For each amount, try using each coin and track the minimum
- Return `-1` if the amount is unreachable (remains `Infinity`), otherwise return the count

**Example:** For coins `[1, 2, 5]` and amount `5`:
- The algorithm finds that 1 coin of value 5 is optimal, returning `1`

**Complexity:** O(amount × coins.length) time, O(amount) space.
