I've implemented `longestNonDecreasing` in `solution.ts`. It runs in O(n log n) time and passes all the checks below.

**How it works:** it keeps a list where entry `k` is the smallest value that can end a non-decreasing subsequence of length `k+1`. For each number, a binary search finds the first entry that is strictly greater than it, and the number replaces that entry. If no entry is greater, the number is added to the end. Searching for "strictly greater" rather than "greater or equal" is what lets equal values extend a subsequence. The answer is the list's final length.

**Checks I ran:**
- **Random arrays:** 2,000 small arrays with many repeated values gave the same answers as a simple O(n²) version.
- **Examples:** `[2,2,2]` → 3, `[5,4,3]` → 1, `[1,3,2,2,4]` → 4.
- **Speed:** a random array of 100,000 values finished in about 4 ms.
