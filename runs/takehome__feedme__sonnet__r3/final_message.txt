**Files**
- **Core logic:** `src/orderController.js` holds the pending queue, the bots and the 10-second processing. Timers are injectable, so the tests run instantly with a fake clock.
- **CLI:** `src/index.js` runs interactively by default, with `normal`, `vip`, `+bot`, `-bot`, `status`, `help` and `quit`. `--demo` runs the scripted scenario that `run.sh` uses.
- **Tests:** `test/orderController.test.js`.
- **Scripts:** `scripts/test.sh`, `scripts/build.sh` and `scripts/run.sh`. `run.sh` writes to `scripts/result.txt`, the path the workflow checks.
- **Docs:** `README.md` has a new solution section at the end.

**Design choice**
- The pending list is sorted by VIP first, then by order number. An order interrupted by `-bot` is re-inserted by the same rule, which puts it back in its original position.
