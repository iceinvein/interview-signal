**What it does**
- **Pending queue:** VIP orders go ahead of Normal ones, and orders of the same type keep their arrival order. The same rule puts an order back in its original spot when the bot working on it is removed.
- **Bots:** each takes one order at a time for 10 seconds, then picks up the next or goes IDLE. `- Bot` removes the newest bot and cancels any order it was cooking.
- **CI output:** `run.sh` runs a scripted demo in real time (about 32 seconds) and writes `scripts/result.txt` with `[HH:MM:SS]` timestamps. The demo covers VIP priority, removing a bot mid-order (order #1001 goes back behind VIP #1004), adding a bot that starts work immediately, and idle bots.
- **Interactive CLI for the interview:** `npm start`, then `n`, `v`, `+`, `-`, `s` (status), `q` (quit).
- **Tests:** they use Node's built-in test runner with fake timers, so the 10-second rule is checked exactly without waiting.
- No dependencies. The README has a new section on how to run it, the design, and assumptions; the original brief is unchanged.
